## What This Project Does

Predicts NYC taxi trip duration (seconds) from pickup/dropoff GPS coordinates and time features.
Built as a production-style ML pipeline covering data ingestion → validation → feature engineering → model training → REST API serving → drift monitoring.

---

## Architecture

```
data/raw/train.csv  (DVC tracked)
        ↓
pipeline/ingest.py      → loads + profiles raw data
        ↓
pipeline/validate.py    → 4-level validation (schema, range, stats, business rules)
        ↓
pipeline/features.py    → engineers 5 features → data/processed/features.csv
        ↓
training/train.py       → Linear Regression + XGBoost, logged to MLflow   [Week 2]
        ↓
serving/api.py          → FastAPI /predict endpoint, Dockerised             [Week 3]
        ↓
monitoring/             → prediction logging, KS-test drift detection       [Week 4]
```

## Setup — Step by Step

### Step 1 — Clone the repository

```bash
git clone https://github.com/2025paml539-lab/mleng-mini-project.git
cd mleng-mini-project
```

### Step 2 — Create a virtual environment

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Mac / Linux
python3 -m venv venv
source venv/bin/activate
```

### Step 3 — Install all dependencies

```bash
pip install -r requirements.txt
```

### Step 4 — Download the dataset

The raw dataset is **not stored in Git** (tracked by DVC). Download it manually:

1. Go to: https://www.kaggle.com/competitions/nyc-taxi-trip-duration/data
2. Join the competition (free) → download `train.zip`
3. Extract `train.zip` → get `train.csv`
4. Place it here:
```
data/raw/train.csv
```

> File size: ~191 MB | Rows: 1,458,644 trips

## Running the Week 1 Pipeline

Run each script from the **project root folder** in order:

### 1. Ingest — load and profile raw data

```bash
python pipeline/ingest.py
```

**Expected output:**
```
[INGEST] Loaded     : 1,458,644 rows x 11 cols
[INGEST] Columns    : ['id', 'vendor_id', 'pickup_datetime', ...]
[INGEST] Nulls      : 0 — all columns complete
[INGEST] trip_duration — min: 1s  max: 3526282s  mean: 959s
[INGEST] Date range : 2016-01-01 → 2016-06-30
[INGEST] Done
```

### 2. Validate — 4-level data quality checks

```bash
python pipeline/validate.py
```

**Expected output:**
```
[L1 SCHEMA]   PASS — all 11 columns present, correct types, 0 nulls
[L2 RANGE]    WARN — 689 rows (0.047%) removed as outliers
[L3 STATS]    PASS — 1,457,955 rows | mean 959s
[L4 BUSINESS] PASS — dropoff > pickup for all rows
[VALIDATE] All checks passed
```

### 3. Feature Engineering — create model-ready features

```bash
python pipeline/features.py
```

**Expected output:**
```
[FEATURES] Engineering features...
  hour_of_day    : range 0-23
  day_of_week    : range 0-6
  is_weekend     : 416,234 weekend trips
  distance_km    : mean=3.44km  max=1240.91km
  pickup_hour_bin: {evening: 499442, afternoon: 430245, morning: 357477, night: 171480}
[FEATURES] Saved : data/processed/features.csv (1,458,644 rows x 6 cols)
[FEATURES] Saved : artifacts/feature_schema.json
[FEATURES] Done
```

### 4. Generate Week 1 Visual Outputs

```bash
python outputs/week1/generate_outputs.py
```

This produces 4 charts in `outputs/week1/`:

| File | What it shows |
|---|---|
| `01_validation_summary.png` | 4-level validation PASS/WARN result |
| `02_trip_duration_distribution.png` | Raw and log-transformed duration |
| `03_engineered_features_overview.png` | All 5 features — distributions and counts |
| `04_nyc_pickup_heatmap.png` | NYC GPS pickup density map |
